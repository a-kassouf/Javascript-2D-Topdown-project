# Javascript-2D-Topdown-project
This repository contains the javascript top down 2D app. 
To run it, make sure that all the images are in the same folder as the javascript script, and simply run the javascript script. 

It is possible to move around with the w-a-s-d keys in the game, use F to do an animation, and E to throw at the beavers.

It's important to note that it was made without external libraries for javascript, meaning it was made from scratch, the movemenets are frames being redrawn every frame, and the framerate function itself is coded.
This was made to showcase saving values via javascript (highscore system) and frame-by-frame simulations.
